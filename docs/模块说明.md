# 模块说明

## 模块划分

| 模块 | app_label | 职责 | 核心表 |
|---|---|---|---|
| 核心 | `core` | 公共抽象基类、班次枚举、总看板 | 无（抽象模型） |
| 库存 | `inventory` | 物料主数据、库存数量、出入库流水 | `Material` / `StockMovement` |
| 生产 | `production` | 产品、工单、报工 | `Product` / `WorkOrder` / `ProductionReport` |
| 质量 | `quality` | 检验单、缺陷明细 | `Inspection` / `DefectRecord` |
| 设备 | `equipment` | 设备台账、点检维保 | `Equipment` / `MaintenanceLog` |
| 人员 | `hr` | 员工档案、排班 | `Employee` / `ShiftSchedule` |

## 约定

### 1. 所有业务表继承 TimeStampedModel

```python
from apps.core.models import TimeStampedModel

class Foo(TimeStampedModel):
    ...
```

自动获得 `created_at` / `updated_at` / `created_by` 三个字段，
并且 `Meta.ordering` 默认按创建时间倒序（新记录在前）。

继承时**不要**覆盖 `Meta` 类，而是继承它：

```python
class Meta(TimeStampedModel.Meta):
    verbose_name = "xxx"
    indexes = [...]
```

### 2. 班次统一用 Shift 枚举

工厂场景几乎所有记录都要挂班次，统一用 `apps.core.models.Shift`：

```python
from apps.core.models import Shift

shift = models.CharField("班次", max_length=16, choices=Shift.choices, blank=True)
```

### 3. 金额与数量一律用 DecimalField

绝不用 `FloatField` 存数量或金额 —— 浮点误差在库存对账时会变成真金白银的麻烦。

```python
quantity = models.DecimalField("数量", max_digits=14, decimal_places=2)
```

### 4. 关联已发生的业务数据用 PROTECT

物料、产品这类被引用的主数据，删除时用 `on_delete=models.PROTECT` 拦住，
避免删掉一个物料导致历史出入库记录失去关联。
只有明细行（如 `DefectRecord` 之于 `Inspection`）才用 `CASCADE`。

### 5. 跨模块聚合放在 core

`core/views.py` 的看板要从多个模块取数。为避免 app 之间互相 import 造成循环依赖，
规则是：**业务模块之间不互相 import，需要汇总时统一由 core 去拿**。

### 6. 后台展示用 list_display 的装饰器方法

不要在模型上写只给后台用的展示逻辑，写在 `admin.py` 里：

```python
@admin.display(description="库存状态")
def stock_state(self, obj):
    if obj.is_below_safety:
        return format_html('<b style="color:#d32f2f">低于安全库存</b>')
    return format_html('<span style="color:#2e7d32">正常</span>')
```

反过来，**业务语义**的计算（如 `WorkOrder.progress`、`Inspection.defect_rate`）
放在模型上作为 `@property`，这样看板、报表、定时任务都能复用。

## 新增一个模块的步骤

1. `python manage.py startapp 新模块 apps/新模块` —— 或手动建目录
2. 写 `apps.py`，设 `name = "apps.新模块"` 和中文 `verbose_name`
3. 写 `models.py`，业务表继承 `TimeStampedModel`
4. 写 `admin.py`，配 `list_display` / `list_filter` / `search_fields`
5. 在 `config/settings.py` 的 `INSTALLED_APPS` 加 `"apps.新模块"`
6. `python manage.py makemigrations 新模块 && python manage.py migrate`

迁移文件**要入库** —— 它是团队协作和部署的基础。个人项目如果嫌乱，
可以在 `.gitignore` 里放开注释忽略它。
